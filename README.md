
# RL Salón de Belleza

Sitio web oficial de RL Salón de Belleza, especializado en trenzas y diseños personalizados en Villa María, Córdoba.

## Sobre el proyecto

Página web moderna, adaptable a celulares, con catálogo de estilos, precios, cursos, productos y solicitudes de turnos por WhatsApp.

## Funcionalidades

- Catálogo de trenzas y precios.
- Galería de inspiración.
- Información sobre cursos de Box Braids.
- Catálogo de productos y accesorios.
- Formulario interactivo para solicitar turnos.
- Contacto directo por WhatsApp.
- Diseño responsive para celulares, tablets y computadoras.

## Tecnologías

- HTML5
- CSS3
- JavaScript
